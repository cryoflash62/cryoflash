Implexe et consanguinité




Description

Ce rapport affiche le nombre d'ancêtre trouvés, le taux de couverture, le taux d'implexe et le coefficient de consanguinité.

Le taux de couverture est le rapport entre les ancêtres connus et les ancêtres possibles (colonne % ci-dessous).

Un implexe est une personne qui apparaît plusieurs fois dans l'arbre d'ascendance. Ainsi, le taux d'implexe est le rapport entre le nombre d'ancêtres cumulés et le nombre d'ancêtres différents.
Exemple: si un individu a 100 ancêtres, mais seulement 80 sont différents, le taux d'implexe est 1 - (80 / 100) = 20%.

Le coefficient de consanguinité d'un individu est la probabilité que deux allèles de cet individu soient identiques. Cela suppose que ses parents aient un ou plusieurs ancêtres identiques.
